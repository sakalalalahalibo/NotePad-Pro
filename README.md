# NotePad Pro (Kotlin + Jetpack Compose)

1. Open this folder in Android Studio (Koala or newer) and let Gradle sync.
2. Run on a device/emulator (minSdk 24).
3. Build > Build APK(s) for an installable file.

App icon: right-click `app/src/main/res` > New > Image Asset, then add
`android:icon="@mipmap/ic_launcher"` to the <application> tag in AndroidManifest.xml.
